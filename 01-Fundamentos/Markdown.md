# 📝 Markdown

## 📌 O que é Markdown?

Markdown é uma linguagem de marcação leve utilizada para formatar textos utilizando uma sintaxe simples.

É muito utilizada em documentação, arquivos README, projetos no GitHub e outras plataformas.

## 🔤 Títulos

Os títulos são criados utilizando o símbolo `#`.

```markdown
# Título 1
## Título 2
### Título 3
```

Quanto maior a quantidade de `#`, menor o nível do título.

## ✨ Formatação

### Negrito

```markdown
**texto em negrito**
```

Resultado:

**texto em negrito**

### Itálico

```markdown
*texto em itálico*
```

Resultado:

*texto em itálico*

### Código

Para destacar uma palavra ou comando:

```markdown
`git status`
```

Resultado:

`git status`

## 📋 Listas

### Lista não ordenada

```markdown
- Python
- Git
- GitHub
- SQL
```

### Lista ordenada

```markdown
1. Estudar
2. Praticar
3. Registrar
4. Revisar
```

## 🔗 Links

A estrutura é:

```markdown
[texto do link](endereço)
```

Exemplo:

```markdown
[GitHub](https://github.com)
```

## 💻 Blocos de código

Para apresentar várias linhas de código:

````markdown
```python
print("Olá, mundo!")
```
````

O texto entre as três crases indica o tipo de código.

## 📊 Tabelas

Exemplo:

```markdown
| Tecnologia | Nível |
|---|---|
| Git | Iniciante |
| GitHub | Iniciante |
| Python | Iniciante |
```
