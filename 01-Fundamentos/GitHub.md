# 🐙 GitHub

## 📌 O que é?

O GitHub é uma plataforma de hospedagem e colaboração para projetos que utilizam Git, um sistema de controle de versão.

Ele permite armazenar projetos, acompanhar alterações, colaborar com outras pessoas e disponibilizar trabalhos em repositórios.

## 🔄 Git x GitHub

### Git

É o sistema de controle de versão.

Permite registrar alterações realizadas nos arquivos de um projeto e manter um histórico dessas modificações.

### GitHub

É uma plataforma que hospeda repositórios Git e oferece recursos para colaboração, documentação, revisão e compartilhamento de projetos.

### Resumindo

**Git = ferramenta de controle de versão**

**GitHub = plataforma para hospedar e colaborar em projetos Git**

## 📦 O que é um repositório?

Um repositório é o espaço onde um projeto é armazenado.

Ele pode conter:

* arquivos;
* pastas;
* códigos;
* documentos;
* imagens;
* README;
* histórico de alterações.

## 📝 O que é um commit?

Um commit é um registro de uma alteração realizada no projeto.

Ele funciona como um ponto no histórico do repositório.

Exemplo:

```text
Projeto criado
      ↓
Commit 1
      ↓
README atualizado
      ↓
Commit 2
      ↓
Novo arquivo adicionado
      ↓
Commit 3
```
