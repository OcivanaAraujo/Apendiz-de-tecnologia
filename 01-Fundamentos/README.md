## 🎯 Objetivo

Construir uma base para compreender como a tecnologia, a programação e os sistemas computacionais funcionam antes de avançar para conteúdos mais específicos.

## 📚 Conteúdos

* Conceitos básicos de tecnologia
* Computação e sistemas
* Lógica de programação
* Algoritmos
* Dados e informação
* Introdução à programação
* Ferramentas de desenvolvimento
* Git e GitHub

## 🧠 O que estou aprendendo

Nesta etapa, o foco é compreender os conceitos fundamentais e desenvolver raciocínio lógico para resolver problemas utilizando tecnologia.

## 📝 Registro de aprendizagem

Os conteúdos, exercícios, dúvidas e descobertas serão registrados nesta pasta conforme o avanço dos estudos.
